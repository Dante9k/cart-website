数据与隐私

适用于购物车 v0.1.0 体验版 · 更新于 2026 年 10 月 28 日

你的购物清单保存在本机

购物车不要求注册或登录。商品名称、链接、图片、价格、规格、收藏和备注保存在当前设备的应用存储中，不会自动同步到我们的服务器或其他设备。当前版本没有账号服务、广告 SDK 或行为分析 SDK。

添加链接时会访问购物平台

粘贴商品链接后，应用会尝试访问对应平台的公开页面，读取其提供的商品名称、图片和标价。该请求会将链接及正常网络连接信息发送给对应平台；加载远程商品图片时，图片服务方也会收到网络请求。应用不会为此读取你在其他 App 中的登录 Cookie，也不会替你登录购物平台。

剪贴板与选取的图片

点击“从剪贴板粘贴”时，应用才会尝试读取剪贴板文字。通过系统选择器选取的商品图片用于当前清单显示，应用会缩小图片后保存在本机。安卓版本还可接收你主动通过其他 App 分享过来的文字链接。

备份、导出与删除

你可以导出 JSON 备份或 CSV 价格表，也可以导入已有备份并合并清单。导出文件可能包含商品链接、价格和个人备注，请自行选择保存与分享的对象。卸载应用或清理应用数据会删除本机清单；请在操作前保存需要的备份。导出的文件不会随卸载自动删除。

官网与安装包下载

本官网用于产品介绍和下载，没有注册、商品录入或在线清单功能，也不主动添加分析 Cookie 或第三方跟踪脚本。网站和安装包由 GitHub Pages、GitHub Releases 提供托管，访问与下载请求会由 GitHub 处理。相关处理方式请参考 GitHub 隐私声明。

体验版说明

当前安卓版本为使用开发证书签名的体验包，尚未完成真机验证。iPhone 版本开发中，暂无可安装版本。商品价格和规格需自行核对，实际成交金额以购物平台结算页面为准。

反馈

如需反馈问题，请前往 GitHub Issues。Issue 内容会公开显示，请勿包含账号凭据、付款信息或不希望公开的个人资料。
