# 购物车官网

“购物车”的中文产品介绍与安卓体验版下载页面。

- 官网：https://dante9k.github.io/cart-website/
- 安卓版本：v0.1.0 预发行体验版，Android 8.0+
- iPhone：开发中，暂无可安装版本

## 内容

此仓库仅保存官网页面、样式、脚本和界面截图。安卓 APK 作为 GitHub Release 附件发布，不包含 App 源码、开发签名密钥或构建工具。截图和页面中的商品价格均为演示数据。

## 本地预览

本网站使用纯 HTML / CSS / JavaScript。使用任意静态 HTTP 服务预览仓库根目录即可，无需安装前端依赖。页面资源采用相对路径，可部署到 GitHub Pages 项目子目录。

## 发布与更新

GitHub Pages 从 `main` 分支根目录发布，`.nojekyll` 禁用 Jekyll 处理。更新页面后推送到 `main`，等待 Pages 部署完成。

下载按钮固定指向 `v0.1.0` 的 `cart-0.1.0-android.apk` 附件。发布后续版本时，先上传并验证新附件，再统一更新页面里的版本、下载地址、包体大小与版本说明。

当前体验包未上架应用商店，尚未完成真机验证。安装与功能边界见官网和 Release 说明。
